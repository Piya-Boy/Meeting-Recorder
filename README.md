# AI Development Workflow

A unified development workflow for Claude Code, Codex, and other AI coding agents.

## Core Concept

One User + One AI Agent.

The AI agent handles the entire development lifecycle:
- Understand requirements
- Explore the repository
- Plan implementation
- Write and modify code
- Test and debug
- Review changes
- Update documentation
- Commit and push when authorized

The user provides requirements and makes final decisions.
